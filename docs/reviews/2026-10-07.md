## Release boundaries

- Host-authorized live Luma and Partiful preflight is mandatory; offline fixtures cannot certify live API behavior or the current authenticated DOM.
- Attendance updates intentionally stop as a whole when any tracked identity is missing, changed or attendance-unknown. Last good data is retained.
- Event, cohort, team, ICP and monitoring-window changes require a reviewed migration; no automatic migration is supplied.
- The application is self-hosted and privately authenticated, not a managed production service. HTTPS, private storage, retention and secret management remain the host's responsibility.
- No reuse license has been selected. Public source visibility alone does not grant an open-source license.
